# 析句

把英文句子拆开：句子成分、时态、从句，以及中文译文。

贴进一句或一段英文，页面会标出主语、谓语、宾语和状语，并用中文说明时态、被动、定语从句和条件句。整句翻译单独给出，点开每个词还能看词性和词义。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:43123](http://127.0.0.1:43123)。

```bash
npm test
```

语法分析有一组固定例句测试，不依赖网络。

## 翻译

整句中文来自 [MyMemory](https://mymemory.translated.net/) 的免费接口，不需要密钥。接口有每日额度；额度用完或网络失败时，语法解析仍然可用，只是译文那一栏会空着。

词义来自 [ECDICT](https://github.com/skywind3000/ECDICT)（MIT License，作者 skywind3000）。仓库里只保留了常用词的精简词表 `data/lexicon.json`，以及词形变化 `data/morph.json`。

句子骨架是规则分析结果，用来帮助看结构。从句套从句、或者句子有歧义时，它可能拆得不完整，语法说明会写得更保守。
